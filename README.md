# 星帽小法師：守護糖霜城

Q 版魔法師守城塔防遊戲。見習法師「波比」和貓頭鷹「咕咕」站在糖霜城的城牆上，用魔法擊退一波波來襲的強盜和怪物。每守住一關就升級，學會更多魔法。

整個遊戲就是一個 HTML 檔，不需要安裝，也不需要網路，用瀏覽器打開就能玩。電腦和手機（橫放）都可以玩。

## 怎麼玩

1. 用瀏覽器（Chrome、Edge、Safari 都可以）打開 `index.html`。如果這個儲存庫開啟了 GitHub Pages，也可以直接用 Pages 的網址線上玩。
2. 按「開始冒險」，選擇關卡。
3. 先選魔法，再點擊敵人施放。按住可以連續施放。
4. 敵人打到城門會扣城堡耐久，耐久歸零就失敗；把整波敵人擊退就過關。

### 操作

| 動作 | 電腦 | 手機 |
|---|---|---|
| 施放魔法 | 滑鼠點擊敵人（按住連發） | 點擊敵人（按住連發） |
| 切換魔法 | 數字鍵 1～5 或點魔法按鈕 | 點畫面下方的魔法按鈕 |
| 終極魔法「星辰隕落」 | Q 或空白鍵 | 點金色星星按鈕 |
| 暫停 | Esc 或 P | 點右上角暫停鈕 |
| 劇情下一句 | 點擊或空白鍵 | 點一下畫面 |

## 遊戲內容

- **30 關、3 章**：草原小鎮、冰雪山道、暗影火山。第 10、20、30 關是 BOSS 戰。
- **13 種魔法**：火球術、冰錐、閃電鏈、魔法護盾、火焰牆、治癒之光、冰霜新星、落雷、流星火雨、時間凍結、暴風雪、雷暴雲，以及終極魔法星辰隕落（每關限用一次）。
- **12 種敵人**：小嘍囉強盜、弓箭盜賊、盾牌兵、炸彈哥布林、狼騎兵、蝙蝠、盜賊巫師、攻城槌、分裂史萊姆（含分裂出的小史萊姆）、隱形刺客、鷹身女妖。
- **3 隻 BOSS**：強盜頭子巴頓、黑翼飛龍、墮落大法師莫恩。
- **劇情**：9 段對話，從序章一路到結局，每段只播一次，可以跳過。
- **背景音樂與音效**：用程式即時合成，音樂和音效可以分開開關。

## 成長系統

- **升級**：第一次通過某一關時，法師升 1 級，到特定等級會學會新魔法。
- **魔法書**：每升一級得到 1 個技能點，每關第一次三星過關再多 1 點。技能點用來把魔法升級（最高 5 級），可以免費重置。
- **出戰欄位**：一開始帶 3 個魔法，Lv6 增加到 4 個，Lv14 增加到 5 個。
- **城堡工坊**：用金幣購買升級，包括城牆加固、魔力水晶、魔力泉源、咕咕助手（貓頭鷹自動攻擊）、城門尖刺。失敗時打倒敵人的金幣也會保留。

## 存檔

- 直接打開 HTML 檔時，進度存在這台電腦的瀏覽器裡。清除瀏覽器資料或換一台電腦，進度就不會跟著走。
- 遊戲也發布在 claude.ai 上（私人連結，只有擁有者能開）：<https://claude.ai/artifact/Qqavv2m3naYFpfgUoxitwj>。在那裡玩時，進度會存到 Claude 帳號，電腦和手機可以接著玩。
- 兩邊的進度是分開的，不會互相合併。
- 想從頭開始，可以在選關畫面按「重置進度」。

## 技術說明

- 純 HTML5 Canvas 和 JavaScript，沒有用任何外部函式庫，也不需要圖片或音檔。
- 角色、敵人、場景全部用程式繪製；音樂和音效用 Web Audio 即時合成。
- 遊戲數值集中在程式開頭的資料表（`SPELLS`、`ENEMY`、`BAL`、`LEVELS`、`UPGRADES`），調整難度時改這幾個地方即可。
